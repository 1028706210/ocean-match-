# 海底消消乐

一个海底主题的单文件三消小游戏，使用 HTML、CSS 和原生 JavaScript 编写，通过 Canvas 绘制角色和棋盘。

## 运行

下载仓库后，用现代浏览器打开 `ocean-match2.html` 即可开始游戏，无需安装依赖或启动后端。

GitHub 的文件页面展示源码。可以选择 **Code → Download ZIP**，解压后打开 HTML 文件。

## 玩法

- 拖动交换相邻的小伙伴，也可以依次点击两个相邻格子。
- 三个同色连成一线即可消除，掉落后的连续消除会形成连锁。
- 关卡模式：在限定步数内完成收集、消除冰块或分数目标。
- 无尽模式：不限步数，挑战最高分。
- 特殊组合会产生条纹、炸弹、十字水母、钻石海螺和彩虹珍珠。
- 提供小锤子、洗牌和提示道具，以及暂停、重新开始、音乐与音效开关。

## 存档和资源

关卡进度、星级、无尽模式最高分和声音设置保存在当前浏览器的 `localStorage` 中。不同浏览器或不同访问地址的存档不会自动同步；清除浏览器数据可能会清除存档。

游戏绘图和逻辑内置于 HTML 文件中。页面会尝试加载 Google Fonts 的「站酷快乐体」，无法加载时使用系统备用字体。
